# Reto 3 — Reglas de sudoers

Guarda aquí las capturas propias del reto de reglas `sudoers`. Documenta:

- La regla inicial concedida a `becario` y los permisos que muestra la inspección.
- La prueba controlada del alcance excesivo de esa regla dentro de la VM.
- La corrección que aplicaste para limitar sudo a la tarea administrativa legítima indicada por el laboratorio. Usa una herramienta de edición/validación segura para `sudoers`.
- La verificación de que el permiso excesivo ya no está disponible y de que la tarea autorizada sigue funcionando.

Añade una frase sobre la lección de seguridad al PDF final. No publiques reglas que contengan secretos.
