# Evidencias — Retos de mínimo privilegio en Linux

Esta carpeta organiza las evidencias de los siete retos. Guarda únicamente capturas obtenidas por ti en la máquina virtual del laboratorio. Cada captura debe mostrar el prompt (usuario y máquina), el comando ejecutado y la salida relevante.

## Evidencias que debes reunir en cada reto

1. **Configuración inicial y prueba controlada:** muestra la mala configuración con comandos de inspección adecuados y demuestra, como `becario`, el efecto que permite.
2. **Corrección aplicada:** muestra los comandos que ejecutaste como administrador para corregir la configuración. Añade una explicación breve en el PDF de entrega.
3. **Verificación:** repite la prueba como `becario` para mostrar que el acceso indebido ya no funciona y comprueba que el uso legítimo continúa operativo.

Consulta el `README.md` de cada carpeta para ver qué aspectos documentar en ese reto. Organiza las capturas con nombres descriptivos, por ejemplo `01-configuracion-inicial.png`, `02-prueba-becario.png`, `03-correccion.png` y `04-verificacion.png`.

## Entrega

La entrega académica solicitada es un único PDF con los siete retos en orden, las evidencias, los comandos, la explicación de las correcciones y una frase de lección aprendida por reto. Esta estructura de carpetas sirve para ordenar el material; no sustituye el PDF.

No subas contraseñas, hashes, claves, datos personales reales ni capturas de sistemas ajenos. Usa solo los datos ficticios del laboratorio y revisa las capturas antes de publicarlas.
