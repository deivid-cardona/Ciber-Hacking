# Evidencias de la actividad

Guarda aquí las capturas originales realizadas durante el laboratorio. Deben mostrar el prompt con usuario y máquina, el comando ejecutado y su salida.

No subas capturas de sistemas ajenos, datos personales o resultados que no hayas obtenido tú. El PDF único de entrega puede mantenerse fuera del repositorio si contiene información identificativa o evidencias que deban entregarse de forma privada.
